# Contemporary_Artificial_Intelligence_Lab
本仓库储存《当代人工智能》课程实验代码。

## Project_1：文本分类

- **任务**：新闻组文本 10 分类
- **方法**：TF-IDF + 逻辑回归 / 线性 SVM
- **运行**：
  ```bash
  cd Project_1
  pip install -r requirements.txt
  python main_experiment.py
  ```
- **输出**：`predictions.csv`、`loss_lr.png`、`loss_svm.png`

所有实验固定随机种子 `42`，结果可复现。
